# Todo List

A simple and functional todo list application built with React, TypeScript, and Vite.

## Features

- Add, delete, and toggle tasks as completed
- Filter tasks by status: All, Active, or Completed
- Data persists in localStorage (survives page reload)
- Keyboard support (press Enter to add a task)
- Responsive and clean UI

## Tech Stack

React | TypeScript | Vite | localStorage | CSS3

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
